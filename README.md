# @sol/design

The design language of [Sol](https://github.com/Draysh/sol), a self-hosted
system of apps named after the solar system. Every app's screens are built
from this package, so they all look and behave the same.

- **[DESIGN.md](DESIGN.md)**: the rules (principles, anatomy of a screen, type,
  light, layout, components, motion, writing).
- **Components** (Svelte 5): `Shell`, `Sheet`, `Body`, `Reticle`, `Card`,
  `Button`, `Field`, `Check`, `Progress`, `RingGauge`, `DataRows`, `Callout`,
  `MoonLink`, `Widget`, `Notices`, `Loader`, `WorldGlyph`.
- **Worlds** (`worlds.ts`): each world's colour, real axial tilt, photo and
  composition.
- **Client** (`@sol/design/client`): the session, Sol's live event stream,
  notifications and typed API clients that every app shares.

## Use it in an app

```sh
npm install git+https://github.com/Draysh/sol-design.git#v0.1.0
```

```svelte
<!-- src/routes/+layout.svelte -->
<script lang="ts">
	import { Shell } from '@sol/design';
	let { children } = $props();
</script>

<Shell world="terra">{@render children()}</Shell>
```

```svelte
<!-- src/routes/+page.svelte -->
<script lang="ts">
	import { Card, Sheet } from '@sol/design';
</script>

<Sheet world="terra" callout={['Walk = done']} rows={[[{ label: 'Streak', value: '12 days' }]]} />
```

New apps start from [sol-planet-template](https://github.com/Draysh/sol-planet-template),
which is already wired up.

## Work on it

```sh
npm install
npm run dev       # the living brand book at http://localhost:5173
npm run check
npm run package   # builds dist/, which apps install
```

To try a change inside an app before tagging a release, run
`npm link` here and `npm link @sol/design` in the app's `web/` folder.

Sol's API types in `src/lib/client/sol.d.ts` are generated by Sol's
`scripts/gen-api.sh`.
