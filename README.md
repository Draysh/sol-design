# @sol/design

The design language of [Sol](https://github.com/Draysh/sol), a self-hosted
system of apps named after the solar system, for **Sol's own web app**. The
worlds' desktop apps are Qt Quick and use the same language from
[sol-quick](https://github.com/Draysh/sol-quick) instead, which has its own
palette (a night, not pure black) in `qml/Theme.qml`.

- **[DESIGN.md](DESIGN.md)**: the rules (principles, anatomy of a screen, type,
  light, layout, components, motion, writing).
- **Components** (Svelte 5): `Shell`, `Sheet`, `PageHead`, `Back`, `Body`,
  `Reticle`, `Card`, `Button`, `Field`, `TextArea`, `Select`, `Toggle`,
  `Check`, `Progress`, `RingGauge`, `DataRows`, `Callout`, `MoonLink`,
  `Widget`, `Notices`, `Loader`, `WorldGlyph`, `Grain`. `AppUpdates`,
  `LinkStatus`, `WayBack` and `WithPlanet` are left from when the worlds'
  apps were Svelte too; Sol's web app doesn't use them.
- **Worlds** (`worlds.ts`): each world's colour, real axial tilt, photo and
  composition.
- **Client** (`@sol/design/client`): Sol's typed API, session and live event
  stream, for Sol's own web app; notices and system notifications for any app.

## Use it in an app

```sh
npm install git+https://github.com/Draysh/sol-design.git#v0.8.0
```

npm 12 installs git dependencies only when the project allows it: add
`allow-git=root` to `.npmrc` and `"allowScripts": { "@sol/design": true }` to
`package.json` (the package builds itself on install).

```svelte
<!-- src/routes/+layout.svelte -->
<script lang="ts">
	import { Shell } from '@sol/design';
	let { children } = $props();
</script>

<Shell world="terra" links={[{ href: '/', label: 'Today', current: true }]}>
	{@render children()}
</Shell>
```

```svelte
<!-- src/routes/+page.svelte -->
<script lang="ts">
	import { Card, Sheet } from '@sol/design';
</script>

<Sheet world="terra" callout={['Walk = done']} rows={[[{ label: 'Streak', value: '12 days' }]]} />
```

Sol's web app (`hub/web`) is the one app that uses it.

## Work on it

```sh
npm install
npm run dev       # the living brand book at http://localhost:5173
npm run check
npm run package   # builds dist/, which apps install
```

To try a change in Sol's web app before tagging a release, run
`scripts/worlds.sh use-local hub` in Sol's repository (it points
`web/package.json` at this folder).

Sol's API types in `src/lib/client/sol.d.ts` are generated by Sol's
`scripts/gen-api.sh`.
