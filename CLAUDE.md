# @sol/design

The design language in Svelte 5, for **Sol's own web app** (`hub/web`, its
only user). The worlds' desktop apps are Qt Quick and get the same language
from sol-quick (`../quick`), and both share one look, Yozora
(`../../docs/yozora.md`): when a rule changes, change it in both.
`tokens.css` holds sol-quick's `Theme.qml` flavours and scale (type,
spacing, corners, motion) between its two `look-from-qml` lines, written by
`node scripts/look-from-qml.mjs` (with `look.gen.ts`; by hand, output
committed, never edited); `fonts.css` and `assets/fonts/` are sol-quick's
fonts cut for the web by `python3 scripts/fonts-for-web.py
../../hub/web/src` (run it again after adding Japanese words, so they are in
the first slice). `DESIGN.md` is the rule book; the components in `src/lib`
keep the rules so the app doesn't have to.

- Change a rule in `DESIGN.md` and the component that enforces it together.
- New components go in `src/lib/components`, are exported from
  `src/lib/index.ts` (`Shortcuts` stays internal to `Shell`), and get a
  section in the living brand book (`src/routes/+page.svelte`).
- Only tokens from `src/lib/styles/tokens.css`; colour only from the
  worlds. World data has one source, sol-quick's `qml/Worlds.qml`:
  `src/lib/worlds.gen.ts` is written from it by
  `node scripts/worlds-from-qml.mjs` (by hand, output committed; never edit
  it), and `worlds.ts` adds types, pictures and the real sky. A new world's
  photograph goes in `src/lib/assets/` and `pictures` in `worlds.ts`.
- A flavour is worn with `data-flavour="<id>"` (the Shell sets it from its
  `flavour`; Sol wears Saturn's); the tokens worked out from a flavour's
  colours (`--surface`, `--line…`, `--raised`, `--text-world`) are declared
  again on every `[data-flavour]`. There is no day mode. Components that
  draw a flavour's mark read it from the Shell's `HERE` context
  (`here.ts`), which also gives a PageHead its section's number and `jp`.
- Motion follows the apps' (`docs/yozora.md`, "Direction"): the Shell turns
  a page the flavour's way (`turn` in `look.gen.ts`, from `Theme.beat`),
  `Sheet.slam` is the one kinetic title, there is no opening; transforms and
  opacity only, a fade with less motion. A failure's notice is said as a
  person would by `notices.show` (`said`, `lineFor`: the apps' lines).
- The stills are the person's own and never enter this package: `Ground`
  shows an address it is given, and the Shell picks one from `stills`
  (`stillFor`), else the drawn sky.
- Glass is `.sol-glass`, brackets `.sol-brackets`, a field's well
  `.sol-well`, focus ticks `.sol-ticks` (base.css); small world marks use
  `.sol-mark` with `--c`.
- `src/lib/client/sol.d.ts` is generated by Sol's `scripts/gen-api.sh`;
  don't edit it by hand.
- `AppUpdates`, `LinkStatus`, `WayBack`, `WithPlanet` and the `AppHere`,
  `AppOffer`, `AppUpdateStatus`, `Moon` and `Door` types are left from the
  Svelte world apps; nothing uses them now.
- `scripts/shot.py` and `scripts/scrollbench.py` are WebKitGTK tools from
  that time. Look at a change in the brand book (`npm run build`, serve
  `build/`, `?flavour=<id>`) and in Sol's web app (a world's page wears its
  flavour) in a headless browser inside `../quick/scripts/hidden.sh`.

Checks: `npm run check`, `npm test` (vitest, in Node: the client's pure helpers,
`src/**/*.test.ts`, which the package leaves out), `npm run package`, `npm run build`. Release by
bumping `package.json`'s version and tagging it (`v<version>`, e.g. `v1.1.0`), then point Sol
at it with `scripts/worlds.sh use-tags <orbit> <design> <quick>` in Sol's
repository.
