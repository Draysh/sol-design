# @sol/design

The design language every Sol world is built from. `DESIGN.md` is the rule
book; the components in `src/lib` keep the rules so apps don't have to.

- Change a rule in `DESIGN.md` and the component that enforces it together.
- New components go in `src/lib/components`, are exported from
  `src/lib/index.ts`, and get a section in the living brand book
  (`src/routes/+page.svelte`).
- Only tokens from `src/lib/styles/tokens.css`: pure black, Outfit, hairlines,
  colour only from the worlds (`worlds.ts`).
- `src/lib/client/sol.d.ts` is generated by Sol's `scripts/gen-api.sh`; don't
  edit it by hand.

Checks: `npm run check`, `npm run package`, `npm run build`. Release by tagging
(`v0.2.0`), then move the apps over with Sol's `scripts/worlds.sh use-tags`.
